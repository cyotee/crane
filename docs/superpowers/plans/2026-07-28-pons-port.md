## Goal

Port open-source **pons** contracts from [ponsdotdev/ponsfamily](https://github.com/ponsdotdev/ponsfamily) into Crane such that:

1. Domain sources under `contracts/protocols/launchpads/ponsFamily/pons/` compile with shared deps remapped to `@crane/contracts/external/...`.
2. Hermetic tests deploy **real** factory + token + Uniswap V3 periphery + **minimal** locker stub and exercise launch / predict / anti-snipe / graduation.
3. Profile-gated Robinhood fork tests bind the **active** live factory + locker and read launch state.
4. Follow-up (not first merge): Service / Aware / Behaviors, docs paths, testnet greenfield smoke.

### Locked decisions (2026-07-28) — do not re-litigate

| Topic | Decision |
|-------|----------|
| **First merge** | Vendor + compile + hermetic launch + active RH fork bind |
| **Domain path** | `contracts/protocols/launchpads/ponsFamily/pons/` ← upstream `contracts/src/**` |
| **Wrappers path** | `.../ponsFamily/{stubs,services,aware,test}` (sibling of `pons/`) |
| **OZ** | Reuse/expand `contracts/external` (v5 semantics); **no** nested OZ under ponsFamily |
| **Locker** | Minimal hermetic stub implementing `IPonsLaunchLocker` |
| **Router** | **Real** Uni V3 periphery only — no thin fake router |
| **Hermetic seed buy** | Use Crane classic `SwapRouter` with `LaunchConfig.routerRequiresDeadline = true` |
| **Configs** | Mirror live docs (1% fee, 1e9 supply, ~4.2 ETH graduation, anti-snipe) |
| **Fork** | Active factory/locker only; `FOUNDRY_PROFILE` + `foundry.toml` RH RPC alias |
| **Diamond / DFPkg** | Out of first ships |
| **Product “v2”** | Not in this GitHub repo — **do not port** |
| **Greenfield** | Testnets only (follow-up) |
| **Consumers** | Hermetic tests + IndexedEx strategies |

## Conventions

### Pragma

- Domain: relax `^0.8.30` → `^0.8.35` (or project default); document in `VENDOR.md`.

### Imports

| From (upstream) | To (Crane) |
|-----------------|------------|
| `@openzeppelin/contracts/...` | `@crane/contracts/external/openzeppelin-contracts-v5/...` |
| `./PonsLauncherToken.sol` etc. | Relative **within** `pons/` **or** `@crane/contracts/protocols/launchpads/ponsFamily/pons/...` — prefer `@crane/` for anything crossing package edges |
| Uni V3 (runtime, hermetic) | Crane `protocols/dexes/uniswap/v3/...` + periphery TestBase |
| Thin `ILaunchpad` “Like” interfaces | Keep faithful in `pons/interfaces/` for domain compile |

**Never** copy upstream `contracts/lib/openzeppelin-contracts` into `ponsFamily/`.

### Hermetic dex / launch config defaults

Mirror live product docs as closely as possible:

| Field | Suggested hermetic default |
|-------|----------------------------|
| `poolFee` | `10000` (1%) |
| `tickSpacing` | `200` |
| `supply` | `1_000_000_000 ether` (1e9 * 1e18 if 18 decimals) — **match factory/token constructor units** from upstream |
| `graduationThreshold` | `4.2 ether` (paired principal scale used by factory) |
| `restrictionBlocks` | `2` (docs: ~two-block window) unless upstream uses different live preset |
| `maxWalletBps` / `maxTxBps` | Match docs (~5% / ~5.5% → 500 / 550) **after verifying** live launch config on fork or docs tables |
| `routerRequiresDeadline` | **`true`** for hermetic (Crane `SwapRouter`) |
| `pairToken` | `address(weth)` from `TestBase_Weth9` |
| `launchFee` | `0.0005 ether` (docs) unless factory storage on fork says otherwise |

**Verify bps / supply units** against factory code + one live `getLaunchConfig` on fork during Phase 0/3 — do not invent conflicting units.

### Seed buy / router (critical)

Upstream `_executeInitialBuy`:

- If `routerRequiresDeadline`: classic V3 `exactInputSingle` **with** `deadline` → matches Crane `ISwapRouter` / `SwapRouter`.
- Else: SwapRouter02-style **without** deadline → used by some **live** RH configs.

**Hermetic:** always configure `routerRequiresDeadline = true` and pass Crane `SwapRouter` address in `DexConfig.swapRouter`.

**Fork:** do not re-run seed buy against live unless necessary; bind + read is enough for minimum.
